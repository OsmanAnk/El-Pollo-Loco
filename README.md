# El Pollo Loco

El Pollo Loco is a 2D jump-and-run game built with object-oriented JavaScript. The player helps Pepe collect coins and salsa bottles to fight enemies.

## Live Demo
[Open live demo](https://osman-annak.developerakademie.net/modul-12/Pollo_Loco/index.html)

## Features
- Character movement and jumping
- Enemy collision detection
- Collectable coins and bottles
- Throwable objects
- Endboss fight
- Sound and game UI

## Tech Stack
- HTML
- CSS
- JavaScript
- Canvas
- Object-oriented programming

## What I Learned
- Building game logic with classes
- Working with canvas rendering
- Collision detection
- Managing game state, animations, and intervals
