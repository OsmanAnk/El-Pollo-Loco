# El Pollo Loco

El Pollo Loco is a 2D jump-and-run game built with object-oriented JavaScript. The player helps Pepe collect coins and salsa bottles to fight enemies.

## Live Demo

[Open live demo](https://osman-annak.developerakademie.net/modul-12/Pollo_Loco/index.html)

## Features

- Character movement and jumping
- Enemy collision detection
- Collectable coins and bottles
- Throwable objects
- Endboss fight
- Sound and game UI

## Tech Stack

- HTML
- CSS
- JavaScript
- Canvas
- Object-oriented programming

## Getting Started

To run this project locally, follow these steps:

1. Clone the repository:

```bash
git clone https://github.com/OsmanAnk/El-Pollo-Loco.git
```

2. Navigate into the project folder:

```bash
cd El-Pollo-Loco
```

3. Open the project:

Open the `index.html` file in your browser or use the Live Server extension in VS Code.
